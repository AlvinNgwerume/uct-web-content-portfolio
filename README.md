## 📌 Project Overview
This repository serves as an interactive demonstration of web content curation, front-end architecture (HTML5/CSS3), accessibility compliance (WCAG 2.1), and Google Analytics (GA4) content auditing—specifically tailored to the University of Cape Town’s **Digital Presence Policy & Guidelines**.

## 🎯 Key Capabilities Demonstrated
1. **Semantic HTML5 & Accessibility:** Structured using clean heading hierarchies (`<h1>`-`<h3>`), semantic container tags, high contrast ratios (`#002B49` navy and `#0072CE` blue), and responsive viewports.
2. **Web Content Governance & Auditing:** Includes a sample audit checklist evaluating link integrity, metadata completeness, and WCAG accessibility standards across high-profile departmental pages.
3. **GA4 Analytics Collation:** Demonstrates performance reporting by linking page metrics (pageviews, engagement time, traffic channels) to actionable UX recommendations.

## 🛠️ Stack & Technologies Used
* **Languages:** HTML5, CSS3
* **Design Standards:** UCT Official Color Palette & Typography
* **Analytics Framework:** Google Analytics 4 (GA4) Collation Metrics
* **Hosting:** GitHub Pages
